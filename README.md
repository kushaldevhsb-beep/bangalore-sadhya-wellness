# SADHYA WELLNESS — BENGALURU
> **Personalised Yoga & Wellness, Brought to Your Space.**

---

## 🌟 Executive Summary
**Sadhya Wellness — Bengaluru** is a high-performance digital wellness platform purpose-built for doorstep in-home yoga, personal therapy, women's wellness, corporate workshops, and apartment society communities across selected Bengaluru neighborhoods.

### Key Business Architecture:
- **Bengaluru (`bangalore.sadhyawellness.com`)**: Primary conversion-focused doorstep wellness service operations.
- **Uttarakhand Roots (`sadhyawellness.com`)**: Brand roots & head office located in Nainital District, Uttarakhand.
- **Sadhya Tours (`tour.sadhyawellness.com`)**: Purposeful spiritual travel, yoga retreats, Char Dham & Neem Karoli Baba journeys.

## 🚀 Quick Start & Commands

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production (outputs to /dist)
npm run build

# 4. Preview production build locally
npm run preview -- --port 4173
```
